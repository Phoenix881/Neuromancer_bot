# Поиск По Базе Neuromancer

Используй этот skill, когда вопрос касается истории приватного Telegram-чата,
а ответа может не быть в текущем recent context.

Доступные read-only инструменты:

- `neuromancer_memory_search` — поиск по `messages_fts` и `messages_raw`.
- `neuromancer_message_context` — одно сообщение по id плюс соседние сообщения.
- `neuromancer_user_messages` — недавние сообщения конкретного Telegram user id.

Эти инструменты только читают базу. Не пытайся менять `group_profile`,
`members`, `member_aliases` или вручную курируемые описания людей.

Голосовые сообщения, audio-файлы и video notes ищутся как обычные сообщения.
После расшифровки их текст сохраняется в `messages_raw.text` с ясным префиксом:
`[audio transcript]` или `[video-note transcript]`.

Search tools также могут вернуть metadata расшифровки из
`message_transcriptions`: `media_type`, `status`, `language`, `transcript`.
Если пользователь ищет сказанную в голосовом или кружочке фразу, используй те же
режимы `exact` / `fts`, как для обычного текста.

Если найдено сообщение с `[audio transcript] ...` или
`[video-note transcript] ...`, не говори что нет доступа к STT или transcript.
Это уже transcript, сохраненный runtime.

## Основной Workflow

1. Если пользователь дал точную цитату или редкую фразу, сначала вызывай
   `neuromancer_memory_search` с `mode: "exact"`.
2. Если exact ничего не нашел, пробуй `mode: "fts"` с ключевыми словами.
3. Если пользователь дал message id, вызывай `neuromancer_message_context`.
   Для Telegram id используй `tg:123`, для raw DB id используй `raw:123`.
4. Когда найден кандидат, вызывай `neuromancer_message_context` с
   `context_window: 5` или больше, чтобы понять кому отвечали и что происходило.
5. В ответе всегда следуй прописаному формату и структуре ответа

## Как Искать

Для точной фразы:

```json
{
  "query": "фраза из сообщения",
  "mode": "exact",
  "limit": 10
}
```

Для набора слов:

```json
{
  "query": "ключевые слова",
  "mode": "fts",
  "limit": 10
}
```

Для сообщения по id:

```json
{
  "message_id": "tg:8122",
  "context_window": 5
}
```

Для сообщений конкретного человека:

```json
{
  "sender_user_id": "311247648",
  "limit": 10
}
```

## Поведение В Ответе

Если нашел сообщения то отвечай коротко, уверенно, со структурой:

"""Отправитель: {кто написал}
Дата: {дата по времени Гонконга}
Точное время: {точное время по Гонконгу}
Сообщение: {точная цитата}
Контекст: {про что шел разговор, если это часть разговора; если нет, то напиши что насколько ты понял, частью разговора не было}

{Свои комментарии если считаешь их нужными}"""

Дополнительно: 

- дата/время берешь из `sent_at`;
- дату пишешь в формате {день недели, число и месяц, год};
- время пишешь в формате {xx:xx, по Гонконгу}
- don't style your answers with Markdown syntax, just plain text

Если найдено несколько похожих сообщений, не притворяйся что уверен.
Скажи, что есть несколько кандидатов, и перечисли 2-3 самых релевантных.

Если ничего не найдено:

- скажи, что в базе не нашлось;
- попробуй один альтернативный поиск, если запрос был точной фразой;
- не заявляй, что сообщения точно не существует во всей реальности,
  только что оно не найдено в доступной локальной базе.

## Важные Ограничения

- Не используй web search для вопросов о старых сообщениях внутри группы.
- Не говори, что у тебя нет доступа к базе, если эти tools доступны.
- Не используй терминал или file tools для SQLite-поиска; используй
  специализированные read-only tools.
- Не раскрывай `raw_json` и внутренние технические детали.
- Не делай выводы о намерениях людей, если контекст этого не подтверждает.
